اتصال افزونه WordPress به دیلندر

لاگین جدا با ایمیل/رمز از افزونه حذف شده است. افزونه کلید را می‌سازد، درخواست اتصال می‌فرستد، و کاربر در سایت دیلندر تأیید یا لاگین می‌کند.

۱. ساخت درخواست اتصال

POST /api/v1/wordpress/connection-requests
Content-Type: application/json

{
  "siteUrl": "https://shop.example.com",
  "installationKey": "PLUGIN_GENERATED_KEY_32PLUS",
  "siteName": "فروشگاه من",
  "metadata": { "wpVersion": "6.8", "pluginVersion": "1.0.0" }
}

پاسخ: requestId، expiresAt (حدود ۱۵ دقیقه)، approveUrl.

۲. تأیید در دیلندر

افزونه approveUrl را باز می‌کند. کاربر با نشست وب تأیید می‌کند:

POST /api/v1/wordpress/connection-requests/:id/approve
Authorization: Bearer WEB_ACCESS_TOKEN

وضعیت: GET /api/v1/wordpress/connection-requests/:id

۳. هدرهای بعدی افزونه

X-Dlander-Installation-Key: PLUGIN_GENERATED_KEY
X-Dlander-Site-Url: https://shop.example.com
JWT وردپرس دیگر لازم نیست. اتصال برقرارشده انقضای اجباری ندارد.

۴. مدیریت از وب

عملEndpoint
فهرستGET /api/v1/users/me/wordpress-sites
نام / غیرفعالPATCH .../:id
قطع اتصالDELETE .../:id
چرخش کلیدPOST .../:id/rotate-key
