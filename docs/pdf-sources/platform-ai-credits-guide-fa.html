راهنمای AI هیبرید

کاربر می‌تواند credit از پلتفرم بخرد، یا API Key شخصی خودش را وصل کند (BYOK). هر دو حالت در یک اپ پشتیبانی می‌شود.

Platform Credits
کلید سرور + کسر credit
BYOK
کلید کاربر · بدون credit
Providerها
OpenAI · Claude · Gemini
فرانت
Chat + Settings کلیدها

۰. مدل هیبرید

حالتAPI KeyCredit پلتفرمفیلد درخواست
PLATFORM_CREDITSکلید env سرورکسر می‌شودبدون credentialId
USER_KEYکلید رمزنگاری‌شده کاربرکسر نمی‌شودبا credentialId
امنیت: کلید شخصی کاربر با AES-256-GCM رمز می‌شود و هرگز در پاسخ API برنمی‌گردد؛ فقط keyHint مثل sk-...wxyz دیده می‌شود.

۳. جریان‌ها

A) با credit: Login → خرید package → بدون credentialId → POST /ai/requests → کسر credit
B) با کلید شخصی: Login → POST /ai/credentials → POST /ai/requests با credentialId → بدون کسر credit

۴. API — Credentials (BYOK)

GET    /api/v1/ai/credentials
POST   /api/v1/ai/credentials
PATCH  /api/v1/ai/credentials/:id
DELETE /api/v1/ai/credentials/:id

۶. API — ارسال Prompt

۶.۱ با credit پلتفرم

POST /api/v1/ai/requests
Authorization: Bearer ACCESS_TOKEN
Idempotency-Key: unique-key

{
  "provider": "openai",
  "model": "gpt-4o-mini",
  "operation": "CHAT",
  "input": {
    "messages": [{ "role": "user", "content": "سلام" }]
  }
}

۶.۲ با کلید شخصی (بدون credit)

POST /api/v1/ai/requests
Authorization: Bearer ACCESS_TOKEN
Idempotency-Key: unique-key-byok

{
  "provider": "openai",
  "model": "gpt-4o-mini",
  "operation": "CHAT",
  "credentialId": "credential-uuid",
  "input": {
    "messages": [{ "role": "user", "content": "سلام" }]
  }
}

پاسخ شامل billingMode است: PLATFORM_CREDITS یا USER_KEY. در حالت USER_KEY مقدار chargedCreditAmount صفر است.

۸. پیاده‌سازی Frontend

۸.۱ صفحات

۸.۲ اتصال کلید

await api('/ai/credentials', {
  method: 'POST',
  body: JSON.stringify({
    provider: 'openai',
    apiKey: userTypedKey,
    label: 'Personal',
    isDefault: true,
  }),
});
// کلید را از state پاک کنید؛ فقط id و keyHint نگه دارید

۸.۳ Chat با انتخاب حالت

const body = {
  provider,
  model,
  operation: 'CHAT',
  input: { messages: [...history, { role: 'user', content }] },
  ...(usePersonalKey ? { credentialId } : {}),
};

const result = await api('/ai/requests', {
  method: 'POST',
  headers: { 'Idempotency-Key': crypto.randomUUID() },
  body: JSON.stringify(body),
});

۸.۴ UX پیشنهادی

  • Toggle یا Select: «استفاده از credit پلتفرم» / «کلید شخصی»
  • اگر کلید شخصی ندارد → لینک به /settings/ai
  • اگر credit کافی نیست و حالت پلتفرم است → modal خرید
  • نمایش badge: Platform یا Your key (sk-...)
