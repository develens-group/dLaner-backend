۰. مدل پلتفرمی چیست؟

در این مدل، شما API key سرویس‌های AI (OpenAI، Claude، Gemini) را در env سرور قرار می‌دهید. کاربران کلید شخصی وارد نمی‌کنند؛ credit از پلتفرم می‌خرند و هر درخواست AI از موجودی آن‌ها کسر می‌شود.

نقشمسئولیت
مالک پلتفرم (شما)API key، قیمت credit، providerها
کاربرثبت‌نام، خرید credit، ارسال prompt
بک‌اندreserve → اجرای AI → capture credit
فرانتUI chat، نمایش balance، flow خرید
امنیت: API key هرگز به فرانت یا کاربر داده نمی‌شود. فقط روی سرور در متغیرهای محیطی نگهداری می‌شود.

۶.۲ API Client

const API = 'http://localhost:3000/api/v1';

async function api<T>(path: string, options: RequestInit = {}): Promise<T> {
  const token = localStorage.getItem('accessToken');
  const res = await fetch(`${API}${path}`, {
    ...options,
    headers: {
      'Content-Type': 'application/json',
      ...(token ? { Authorization: `Bearer ${token}` } : {}),
      ...options.headers,
    },
  });
  const body = await res.json();
  if (!res.ok) throw new Error(body.error?.message ?? 'Request failed');
  return body.data;
}

۷. نکات UX و امنیت فرانت

  • قبل از ارسال، available <= 0 → disable دکمه Send
  • برای هر درخواست AI یک Idempotency-Key جدید (UUID)
  • درخواست AI sync است؛ loading state ۵–۳۰ ثانیه‌ای طبیعی است
  • API key هرگز در localStorage یا env فرانت نباشد
  • تاریخچه از GET /ai/requests برای sidebar
Cursor IDE API عمومی برای کاربر ندارد. در این پلتفرم OpenAI، Anthropic و Gemini پشتیبانی می‌شوند.
